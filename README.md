# Deep brain stimulation for the treatment of tremor in Parkinson's disease

Individual project for **Neuro-engineering**, Reykjavík University, Erasmus 2020/2021.

Review report ([PDF](DBS_tremor_Parkinson_report.pdf)) covering:

1. **History of neuromodulation** — from early electrical stimulation for pain to modern DBS.
2. **Parkinson's disease** and the basal-ganglia structures involved in tremor.
3. **DBS engineering** — stimulation parameters, voltage distribution around the electrode, overall system architecture (implantable pulse generator, extension, lead).
4. Analysis of a commercial system: **Medtronic 3389 DBS lead kit** and its implant procedure.

Neuroengineering · medical devices · bioelectric fields · scientific literature review
